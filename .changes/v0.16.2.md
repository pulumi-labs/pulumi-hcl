## v0.16.2 - 2026-08-29

### Bug Fixes

- [runtime] Expose a resource's or data source's `timeouts` block as an attribute typed by the operations it declares; accept `default` [#439](https://github.com/pulumi/pulumi-hcl/pull/439)

- [runtime] Preserve spec-form `aliases` (such as `noParent`) on components, so re-parenting an aliased component no longer recreates it [#543](https://github.com/pulumi/pulumi-hcl/pull/543)

- [language-host] Pin the `terraform-provider` plugin version in install specs so `pulumi install` no longer reuses a stale cached release; the pin can be overridden with the `terraformProviderVersion` runtime option in `Pulumi.yaml` [#204](https://github.com/pulumi/pulumi-hcl/pull/204)

### Dependencies

- Update golang.org/x/mod to v0.40.0

- Update github.com/pulumi/pulumi/pkg/v3 to v3.260.0
