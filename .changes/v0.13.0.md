## v0.13.0 - 2026-08-04

### Improvements

- [converter] Implement `pulumi import --from hcl` (ConvertState): read Terraform/OpenTofu state and emit resource imports resolved through the provider mapper, so TF state can be pulled into a Pulumi HCL project [#334](https://github.com/pulumi/pulumi-hcl/pull/334)

- [converter] Providers resolve from the state's per-resource provider addresses instead of a type-prefix heuristic [#478](https://github.com/pulumi/pulumi-hcl/pull/478)

- [runtime] Add `protect` to resource and module `pulumi` blocks [#344](https://github.com/pulumi/pulumi-hcl/pull/344)

- [runtime] Move to `pulumi/pulumi-hcl`; rename the SDK packages to `@pulumi/hcl`, `pulumi_hcl` and `Pulumi.Hcl` [#480](https://github.com/pulumi/pulumi-hcl/pull/480)

- [runtime] Add `provider::terraform::encode_expr` [#193](https://github.com/pulumi/pulumi-hcl/pull/193)

- [runtime] Add `provider::terraform::encode_tfvars` [#191](https://github.com/pulumi/pulumi-hcl/pull/191)

- [runtime] Add `provider::terraform::decode_tfvars` [#190](https://github.com/pulumi/pulumi-hcl/pull/190)

- [converter] `pulumi import --from hcl` supplies resource values from the state file: outputs land verbatim (skipping the provider's Read), sensitive values import as secrets, and resources whose values cannot be translated still import by id [#479](https://github.com/pulumi/pulumi-hcl/pull/479)

- [converter] `pulumi import --from hcl` correctly imports native terraform resources [#322](https://github.com/pulumi/pulumi-hcl/pull/322)

- [converter] `pulumi import --from hcl` imports `terraform_data` resources as a `Stash`, with their values supplied from the state [#491](https://github.com/pulumi/pulumi-hcl/pull/491)

- [converter] `pulumi import --from hcl` imports resources declared in modules, under the module components the runtime registers [#497](https://github.com/pulumi/pulumi-hcl/pull/497)

- [codegen] Support the `providers` option on components [#494](https://github.com/pulumi/pulumi-hcl/pull/494)

- [runtime] Lowercase the built-in function names (`fileasset`, `pulumiresourceurn`, …) to match Terraform naming [#504](https://github.com/pulumi/pulumi-hcl/pull/504)

- [runtime] Hydrate module input dependencies where possible [#507](https://github.com/pulumi/pulumi-hcl/pull/507)

### Bug Fixes

- [runtime] Enforce `lifecycle { prevent_destroy }` from current configuration, so removing the resource block destroys the instance in one apply [#344](https://github.com/pulumi/pulumi-hcl/pull/344)

- [runtime] Fix preview of provider references with a not-yet-known id and of resource-reference properties (`ref.value`) [#467](https://github.com/pulumi/pulumi-hcl/pull/467)

- [runtime] Support strings containing non-UTF8 bytes [#268](https://github.com/pulumi/pulumi-hcl/pull/268)

- [language-host] Reject lifecycle arguments, provisioner/connection/timeouts blocks, and unsupported `pulumi` options on `data` blocks [#471](https://github.com/pulumi/pulumi-hcl/pull/471)

- [runtime] Support `MaxItemsOne`-flattened list and set attributes: accept attribute-syntax assignment and re-expand values on output [#489](https://github.com/pulumi/pulumi-hcl/pull/489)

- [language-host] Key provider-requirement satisfaction by source, so `pulumi install` converges when a child module's provider source differs from the root's `required_providers` [#490](https://github.com/pulumi/pulumi-hcl/pull/490)

- [runtime] Resolve outputs of creates skipped by `--target` as unknown instead of null [#496](https://github.com/pulumi/pulumi-hcl/pull/496)

- [runtime] Carry a module's `providers` map on its component registration, so remote components inside the module inherit the passed-in providers [#496](https://github.com/pulumi/pulumi-hcl/pull/496)

- [runtime] Defer data source reads whose arguments come from resources pending creation [#496](https://github.com/pulumi/pulumi-hcl/pull/496)

- [runtime] Fail on invalid `aliases` expressions instead of silently ignoring them; add `pulumiResourceURN` [#502](https://github.com/pulumi/pulumi-hcl/pull/502)

- [runtime] Accept nested property paths in `hide_diffs` and `replace_on_changes` [#501](https://github.com/pulumi/pulumi-hcl/pull/501)

- [runtime] Module components record the arguments they were passed instead of intermittently dropping them [#506](https://github.com/pulumi/pulumi-hcl/pull/506)
