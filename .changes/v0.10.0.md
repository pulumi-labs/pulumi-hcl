## v0.10.0 - 2026-07-13

### Improvements

- [runtime] Support provider-defined functions (`provider::<name>::<function>`) [#315](https://github.com/pulumi-labs/pulumi-hcl/pull/315)

- [runtime] Support `terraform.workspace`, resolving to the current stack name [#338](https://github.com/pulumi-labs/pulumi-hcl/pull/338)

- [runtime] Support `for_each` on aliased `provider` blocks and indexed provider instance references [#343](https://github.com/pulumi-labs/pulumi-hcl/pull/343)

### Bug Fixes

- [resource-host] Forward provider routing fields (package ref, provider, version) on data source invokes inside modules run via a direct `hcl.Module`, fixing "Invoke not found" errors [#325](https://github.com/pulumi-labs/pulumi-hcl/pull/325)

- [runtime] Fix a panic when a `provisioner` or `connection` block references another resource's outputs or a sensitive value [#333](https://github.com/pulumi-labs/pulumi-hcl/pull/333)

- [runtime] Fix `sum` panicking on a `null` element [#336](https://github.com/pulumi-labs/pulumi-hcl/pull/336)

- [runtime] Fix a panic when a `timeouts` block value or a `pulumi` block option (`retain_on_delete`, `version`, `plugin_download_url`, `env_var_mappings`) is sensitive [#337](https://github.com/pulumi-labs/pulumi-hcl/pull/337)

- [runtime] Fix panics when a `dynamic` block's `for_each` is unknown during preview, null, or not iterable [#339](https://github.com/pulumi-labs/pulumi-hcl/pull/339)

- [runtime] Fix `anytrue` returning unknown during preview when a known `true` element is present [#335](https://github.com/pulumi-labs/pulumi-hcl/pull/335)

- [runtime] Reject `base64decode` results that are not valid UTF-8 [#341](https://github.com/pulumi-labs/pulumi-hcl/pull/341)

- [runtime] Enforce `precondition` and `postcondition` blocks on data sources [#342](https://github.com/pulumi-labs/pulumi-hcl/pull/342)

- [runtime] Support merging a sequence of mappings and multiple `<<` keys in `yamldecode` [#347](https://github.com/pulumi-labs/pulumi-hcl/pull/347)

- [runtime] Resolve `providers = { x = x }` module arguments and bare `provider = x` references when no `provider "x"` block exists, instead of failing with `unknown node "x"`; report `missing provider` for `providers` entries the parent scope does not declare [#348](https://github.com/pulumi-labs/pulumi-hcl/pull/348)

- [runtime] Fix `Unsupported attribute` errors when traversing unknown nested object attributes during preview [#349](https://github.com/pulumi-labs/pulumi-hcl/pull/349)

- [runtime] Fix `Invalid index` errors when indexing into a MaxItems=1 block that is unknown during preview [#351](https://github.com/pulumi-labs/pulumi-hcl/pull/351)

- [runtime] Run `precondition`, `postcondition`, and provisioner blocks in modules consumed as components [#352](https://github.com/pulumi-labs/pulumi-hcl/pull/352)

- [runtime] Exclude `.git` and `.terraform` artifacts when bundling a module into a parameterized package [#353](https://github.com/pulumi-labs/pulumi-hcl/pull/353)
