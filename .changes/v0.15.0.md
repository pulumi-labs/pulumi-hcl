## v0.15.0 - 2026-08-12

### Improvements

- [runtime] Name the participating nodes in dependency-cycle errors instead of `Cycle found` [#526](https://github.com/pulumi/pulumi-hcl/pull/526)

- [resource-host] Serve one component per consumable module directory (root and `modules/<name>`), including packages with no root `.tf` files [#529](https://github.com/pulumi/pulumi-hcl/pull/529)

- [runtime] Support OpenTofu's `language` block, honoring `compatible_with { pulumi = "..." }` version constraints [#531](https://github.com/pulumi/pulumi-hcl/pull/531)

### Bug Fixes

- [converter] Project the imported state's `id` onto the dynamic bridge's renamed id property on `import --from hcl` [#512](https://github.com/pulumi/pulumi-hcl/pull/512)

- [resource-host] Correctly type unlabeled properties [#516](https://github.com/pulumi/pulumi-hcl/pull/516)

- [runtime] Fix false `Cycle found` when a data source reaches a resource only through a root local [#514](https://github.com/pulumi/pulumi-hcl/pull/514)

- [resource-host] Forward resource hooks attached to an HCL component [#542](https://github.com/pulumi/pulumi-hcl/pull/542)

- [resource-host] Report module parse failures and other invalid-input errors as gRPC `InvalidArgument` instead of `Unknown` [#530](https://github.com/pulumi/pulumi-hcl/pull/530)
