## v0.11.0 - 2026-07-21

### Improvements

- [codegen] Convert and eject multi-argument invokes as `provider::<name>::<fn>(...)` provider-defined function calls [#363](https://github.com/pulumi/pulumi-hcl/pull/363)

- [runtime] Support `recover(value, recovery)` for recovering from failed resources under continue-on-error [#366](https://github.com/pulumi/pulumi-hcl/pull/366)

- [runtime] Support extension-parameterized packages, whose resources and functions extend a base provider's namespace [#367](https://github.com/pulumi/pulumi-hcl/pull/367)

- [runtime] Add a `pulumi { name = ... }` resource option that overrides an instance's Pulumi logical name, evaluated per instance with `count.index`/`each.key` in scope [#382](https://github.com/pulumi/pulumi-hcl/pull/382)

- [codegen] Pin the Pulumi logical names of resources and module calls inside generated component sources via `pulumi { name = "${pulumi.module.name}-..." }` [#391](https://github.com/pulumi/pulumi-hcl/pull/391)

- [runtime] Join module-nested names with `.` so distinct addresses cannot collide; add `pulumi.module.name` and a module-block `pulumi { name = ... }`; a resource's `pulumi { name }` is now the full logical name [#391](https://github.com/pulumi/pulumi-hcl/pull/391)

- [runtime] Add `ephemeralasnull`; hide diffs of resource properties that ephemeral values flow into [#402](https://github.com/pulumi/pulumi-hcl/pull/402)

- [runtime] Return meaningful gRPC status codes (`NotFound`, `Unauthenticated`, `PermissionDenied`, `Unavailable`, `InvalidArgument`, `Unimplemented`) from `Parameterize` and `GetSchema` failures [#406](https://github.com/pulumi/pulumi-hcl/pull/406)

- [runtime] Support the `_` meta-argument escaping block in `resource`, `data`, `provider`, `module`, and `provisioner` blocks [#410](https://github.com/pulumi/pulumi-hcl/pull/410)

- [runtime] Schedule `count`/`for_each` instances individually, so a reference to a single instance no longer waits on the whole resource [#422](https://github.com/pulumi/pulumi-hcl/pull/422)

- [runtime] Compress the module parameterization value baked into the generated `schema.json` [#436](https://github.com/pulumi/pulumi-hcl/pull/436)
