## v0.4.0 - 2026-05-21

### Improvements

- [runtime] Add "did you mean" on unknown token errors when appropriate [#149](https://github.com/pulumi-labs/pulumi-hcl/pull/149)

- [converter] Round-trip heredocs when converting into and out-of PCL [#152](https://github.com/pulumi-labs/pulumi-hcl/pull/152)

### Bug Fixes

- [runtime] Don't corrupt the Pulumi resource name when a resource's HCL type contains dots [#140](https://github.com/pulumi-labs/pulumi-hcl/pull/140)

- [runtime] Fix token lookup for functions with get & modules [#144](https://github.com/pulumi-labs/pulumi-hcl/pull/144)

- [runtime] Do not panic on unknown values in yamlencode [#143](https://github.com/pulumi-labs/pulumi-hcl/pull/143)

- [converter] Fix handling of optional(T) when converting from other languages [#150](https://github.com/pulumi-labs/pulumi-hcl/pull/150)

- [language-host] Expect local SDK files where `pulumi package add` puts them [#160](https://github.com/pulumi-labs/pulumi-hcl/pull/160)

## v0.3.2 - 2026-05-19

## v0.3.0 - 2026-05-12

### Improvements

- [codegen] Add a `SkipRequiredProvidersVersion` option to `GenerateProgram` that omits the `version` attribute from each `required_providers` entry while keeping `source`, for use by SDK-doc generators that should not bake the provider version into emitted snippets [#120](https://github.com/pulumi-labs/pulumi-hcl/pull/120)

- [runtime] Allow calling `length` on strings [#122](https://github.com/pulumi-labs/pulumi-hcl/pull/122)

### Bug Fixes

- [codegen] Avoid a nil-pointer panic in `GenerateProgram` when a resource scope traversal references a `pcl.Resource` whose schema was not populated (e.g. when the binder ran with `SkipResourceTypechecking`) [#119](https://github.com/pulumi-labs/pulumi-hcl/pull/119)

- [language-host] Avoid a panic in the HCL parser when a `required_providers` entry omits the optional `version` attribute [#120](https://github.com/pulumi-labs/pulumi-hcl/pull/120)
