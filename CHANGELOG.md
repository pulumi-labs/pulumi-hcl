- [runtime] `sum` accumulates with arbitrary-precision numbers instead of float64, so large integers and decimals stay exact [#173](https://github.com/pulumi-labs/pulumi-hcl/pull/173)

- [runtime] `textencodebase64` and `textdecodebase64` honor the named IANA encoding instead of always treating the bytes as UTF-8 [#174](https://github.com/pulumi-labs/pulumi-hcl/pull/174)

- [runtime] `formatdate` matches Terraform: correct 24-hour vs 12-hour tokens, timezone tokens, and single-quoted literals [#175](https://github.com/pulumi-labs/pulumi-hcl/pull/175)

- [runtime] Resolve module sources that include a registry host (e.g. `registry.terraform.io/cloudposse/label/null`) via service discovery, matching OpenTofu and Terraform [#186](https://github.com/pulumi-labs/pulumi-hcl/pull/186)

- [runtime] `terraform_data` from the builtin `terraform` provider is handled internally (lowered onto the engine's builtin `Stash` resource) instead of being resolved to a non-existent external plugin [#187](https://github.com/pulumi-labs/pulumi-hcl/pull/187)

- [runtime] A module input variable declared `nullable = false` now substitutes its default when the caller passes `null`, matching Terraform and OpenTofu [#185](https://github.com/pulumi-labs/pulumi-hcl/pull/185)

- [runtime] `cidrhost` matches OpenTofu: a negative host number counts back from the end of the prefix's address range, and a host number that exceeds the available host bits is rejected rather than silently overflowing into the network portion [#192](https://github.com/pulumi-labs/pulumi-hcl/pull/192)

- [runtime] `cidrnetmask` matches OpenTofu: an IPv6 prefix is rejected with an error rather than rendering a mask, since a netmask is an IPv4-only concept [#194](https://github.com/pulumi-labs/pulumi-hcl/pull/194)

- [runtime] `templatefile` matches OpenTofu: the file is rendered as a full HCL template, so interpolations may call functions and use `%{ for }` / `%{ if }` directives, rather than performing a naive `${name}` string substitution [#200](https://github.com/pulumi-labs/pulumi-hcl/pull/200)

- [runtime] `yamlencode` matches OpenTofu: keys and string scalars are quoted and block sequences stay un-indented under their key. [#202](https://github.com/pulumi-labs/pulumi-hcl/pull/202)

- [runtime] `yamldecode` matches OpenTofu by delegating to go-cty-yaml [#203](https://github.com/pulumi-labs/pulumi-hcl/pull/203)

- [runtime] `tolist`, `toset`, and `tomap` match OpenTofu: a tuple or object with differing element types is unified to a common type instead of erroring. [#206](https://github.com/pulumi-labs/pulumi-hcl/pull/206)

- [runtime] `cidrhost`, `cidrnetmask`, `cidrsubnet`, and `cidrsubnets` match OpenTofu: IPv4 prefixes whose octets have leading zeros are accepted and interpreted as decimal instead of erroring. [#209](https://github.com/pulumi-labs/pulumi-hcl/pull/209)
